# PRO-014F2 提案：個人空間的 Pro 呈現

> 狀態：提案（只寫文件），等待擁有者決定 §9。排行榜的 Pro 光環與標記已由 PRO-014F1 完成（#253、#255）。

## 1. 結論

- 建議先做 **F2A：只顯示的身分標記**，不碰經濟、不新增素材、不改資料庫：
  - 個人空間頁頂端的狀態列與首頁 Orbit Window 標題旁，各放一個小的「✦ Pro」標記（沿用 PRO-014F1 的樣式與各主題的文字顏色）；
  - Orbit 夥伴在 Pro 開始與結束時各說一次中性的話，**不推銷、不提價格、不在結束時製造失落感**。
- Pro 專屬的外觀內容（新的房間風格、夥伴形象或主角服裝）列為 **F2B（選做）**：只限新增的內容，現有的免費內容永遠不鎖；要做時另寫素材提案。
- **不建議**讓 Pro 影響進度（多金幣、專案加速、額外房間）：違反個人空間「真實行動優先」與「有價值的獎勵是確定的」原則，也會讓排行榜失去可比性。

## 2. 現況（2026-11-19 的 main）

- **個人空間 V2 沒有任何 Pro 的呈現**：狀態列只有等級、金幣、Momentum 與待揭曉事件（`pages/personalSpaceV2.js` 的 `pageMarkup()`）；首頁的 Orbit Window 標題旁只有 Momentum（`personalSpace/v2/ui/orbitWindow.js`）。
- **Pro 的判定**：client 顯示一律讀 `storage.isProUser()`（server 的 `my_pro_status()` 投影，PRO-014B／H）。它和排行榜 `get_leaderboard()` 的 `is_pro` 同源：`is_pro_active()` 把**試用期也算 Pro**（011）。
- **已有的 Pro 功能**：主題（SUB-06）、保護卡（SUB-09）、歷史深度（SUB-05）、排行榜光環與標記（PRO-014F1）。`tests/unit/proGateCallSites.test.js` 逐一列出 `storage.isProUser()` 的呼叫位置。
- **個人空間的原則**（`docs/personal-space-v2-product-spec.md` §3.2）：真實行動優先；每個獎勵有清楚來源；有價值的獎勵是確定的；夥伴的話不得羞辱、威脅或情緒勒索。
- **付費的原則**（`docs/monetization.md`）：降級後不顯示恐嚇性警告，只說「以下功能在 Pro 中提供」；免費版永不過期，資料永不刪除。
- **可用的外觀**：5 套房間風格（預設、明亮北歐、日式和風、夜貓工作室、深木書房）、兩種畫風（全 Q 版、全像素）、6 套主角與 6 種夥伴形象，全部免費。

## 3. 目標與不做的事

- **目標**：
  - Pro（含試用）使用者在自己的空間裡看得到身分，和排行榜一致；
  - 不讓非 Pro 使用者覺得被比下去或被催促；
  - 只是顯示：不改獎勵、金幣、專案、Momentum，也不回寫任何 entitlement。
- **不做**：
  - 鎖住任何現有的免費內容；
  - 夥伴推銷 Pro、提價格或倒數；
  - 新增資料庫欄位或 RPC（F2A 不需要）；
  - 在個人空間顯示「升級」按鈕（升級入口維持在設定頁）。

## 4. 選項

| | 內容 | 成本 | 風險 |

## 5. 建議的第一階段：F2A（A1 ＋ A2）

### 5.1 身分標記（A1）

- **位置**：
  - 個人空間頁的狀態列，在「等級 N」之後：`<span role="listitem" class="pro-badge--inline personal-space-v2-pro">✦ Pro</span>`；
  - 首頁 Orbit Window 的標題列，在 Momentum 之前，同樣大小；
  - 編輯模式與世界模式都顯示。
- **來源**：`storage.isProUser()`，只在畫面建立時讀一次（和其他 gate 一樣，換日或 entitlement 重新整理時頁面會重畫）。不寫進 V2 state、不進 reward ledger。
- **樣式**：沿用 `.pro-badge--inline` 與 PRO-014F1 收尾後各主題的 `--on-primary`（每個主題對比 ≥ 4.5:1，已有測試）。沒有動畫，不需要 reduced motion 的處理。
- **無障礙**：`aria-label="Orbit Pro 會員"`；只是狀態，不可點。
- **訪客**：不顯示（訪客不會是 Pro）。

### 5.2 夥伴的兩句話（A2，文案需核准）

| key | 何時 | 建議文案 |
|---|---|---|
| `companion.pro.started` | 這台裝置第一次看到這個帳號是 Pro（含試用開始） | 「謝謝你支持 Orbit。這裡的一切照舊，你累積的每一步都算數。」 |
| `companion.pro.ended` | 這台裝置上次看到是 Pro，這次不是 | 「這個空間和你累積的一切都還在，我也還在。」 |

- **只說一次**：每個帳號在這台裝置記一個「上次看到的 Pro 狀態」（localStorage `orbit_ps_pro_seen:<帳號>`，值為 `pro`／`free`）。狀態改變時，夥伴卡片的訊息在**當天**換成這句（之後回到一般的訊息），並記下新的狀態；第一次記錄（沒有舊值）不說話，避免舊使用者更新後突然收到。
- **語氣規則**（個人空間 §3.2 第 5 點）：不提價格、不提「升級」、不倒數試用天數、結束時不說「失去」。
- **不影響**：獎勵、揭曉事件、關係階段（AI-202）都不變。

### 5.3 授權與安全（PRO-014F 的完成條件）

- 兩者都是**純顯示**：沒有新增任何有價值的資料、API 或操作，不需要 server 端強制；交付時在 PR 與 `tasks.md` 列出這兩個新的 `storage.isProUser()` 呼叫位置，並更新 `proGateCallSites` 的清單（標註「顯示」）。
- 文字都是固定字串（不含使用者輸入），不需要額外的 escaping。

### 5.4 INFRA-105

- 判斷「這次要不要說」與讀寫本機記錄放在新模組（例如 `personalSpace/v2/proPresence.js`），既有的 SHELL 模組只 import 它的新 export；文案加在 `companionDialogue.js` 的表裡（既有 export，只多了 key）。

## 6. 後續（選做）：F2B Pro 專屬外觀

只有擁有者想要時才做，另寫素材提案。先定的規則：

- **只限新增的內容**：現有 5 套房間風格、2 種畫風、6 套主角、6 種夥伴全部維持免費。
- **選擇器**：Pro 內容在 Edit Mode 的「風格與角色」裡顯示，非 Pro 時加上 SUB-04 的鎖定樣式；點了只說明「這個外觀在 Pro 中提供」，不跳付款。
- **降級**：選擇保留在 V2 state（不刪），場景改顯示預設；重新成為 Pro 時恢復。不顯示警告（付費原則）。
- **授權**：外觀是純顯示，client 判斷即可；但若素材本身要防止非 Pro 下載，需要私有 bucket 與 server 授權（另議）。
- **成本**：一件房間裝飾 ≈ 2 畫風 × 日夜 × 5 套房間風格 = 20 張渲染與擺放；一套房間風格 ≈ 房間 ＋ 8 件家具 × 2 畫風 × 日夜。

## 7. 驗收（F2A）

- Pro、試用、過期、免費、訪客五種狀態下，個人空間狀態列與首頁 Orbit Window 的標記顯示正確。
- 夥伴的兩句話：免費 → Pro 說一次 `started`，Pro → 免費說一次 `ended`；同一狀態重新整理不再說；第一次記錄不說；換帳號各自記錄。
- 各主題標記對比 ≥ 4.5:1（既有的 `badgeContrast` 測試）。
- `proGateCallSites` 更新；沒有任何獎勵、金幣、專案數字因 Pro 改變（既有的 reward 測試不變）。
- e2e：Pro 與免費各一，截圖確認首頁卡片沒有擠壓（320px 寬）。

## 8. 風險與已知限制

- **projection 過期**：`storage.isProUser()` 依賴快取的投影；剛到期但還沒重新整理時，標記可能多顯示一段時間。這只是顯示，和其他 gate 一致，不另外處理。
- **多台裝置**：夥伴的話以「這台裝置上次看到的狀態」判斷，每台裝置各說一次。
- **首頁空間**：Orbit Window 標題列在 320px 寬時已有 Momentum；標記放不下時改成只顯示「✦」並保留 `aria-label`。

## 9. 需要擁有者決定

1. **範圍**：F2A（A1 ＋ A2，建議）／只做 A1／F2A 並規劃 F2B／都不做（只保留排行榜）。
2. **標記位置**：個人空間狀態列 ＋ 首頁 Orbit Window（建議）／只有個人空間頁。
3. **夥伴的兩句話**：照 §5.2 的文案（建議）／修改文案／不說話。
4. **Orbit Window 光暈（A3）**：不做（建議，首頁卡片的焦點留給專案進度）／做。
5. **試用期**：顯示為 Pro（建議，和排行榜一致）／只有付費才顯示。
6. **F2B**：先不做（建議）／要做，並指定先做哪一類（房間風格／夥伴形象／主角服裝）與素材預算。
